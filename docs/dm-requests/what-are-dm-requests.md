# What are DM Requests?

DM requests are how creators connect on JustCollabs. Instead of open messaging, you send a request that the other person can accept or decline. This keeps conversations consensual and spam-free.

## Sending a DM Request

To send a request you need a JustCollabs account. Visit a creator's profile and tap **Send DM Request**. You'll need to:

- **Verify your identity** with Twitter (X) or Bluesky
- **Write a message** introducing yourself (up to 1,000 characters)
- **Share your location** (country and city)

## Receiving DM Requests

Incoming requests appear in your **Requests** tab (bottom navigation). For each request you can see the sender's social media handles, follower count, location, and message. You can **accept**, **ignore**, or **reject** each request.

Once accepted, you can both chat freely through the **Messages** tab.

## Notification Settings

You can control how you're notified about new DM requests in **Settings > Notifications** — choose to receive email notifications for all requests, only from verified creators, or none at all.
