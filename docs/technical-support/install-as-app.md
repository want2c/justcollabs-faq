# How do I install JustCollabs as an app?

JustCollabs is a **Progressive Web App (PWA)**, which means you can install it on your phone or desktop for a native app-like experience — no app store needed.

## Install on iPhone / iPad (Safari)

1. Open **justcollabs.com** in Safari
2. Tap the **Share** button (square with arrow) at the bottom of the screen
3. Scroll down and tap **"Add to Home Screen"**
4. Tap **"Add"** to confirm
5. JustCollabs will now appear as an app icon on your home screen

## Install on Android (Chrome)

1. Open **justcollabs.com** in Chrome
2. Tap the **three-dot menu** (top right)
3. Tap **"Add to Home screen"** or **"Install app"**
4. Tap **"Install"** to confirm
5. JustCollabs will appear in your app drawer and home screen

## Install on Desktop (Chrome / Edge)

1. Open **justcollabs.com** in Chrome or Edge
2. Look for the **install icon** in the address bar (or click the three-dot menu)
3. Click **"Install JustCollabs"**
4. The app will open in its own window and appear in your applications

## Benefits of installing as an app

- **Full-screen experience** — no browser address bar or tabs
- **Home screen access** — launch with a single tap, just like a native app
- **Faster loading** — cached resources load quickly
- **Push notifications** — receive alerts for new messages and requests (when enabled)
- **Works offline** — basic functionality available without internet

## Is this the same as a native app?

Yes, the PWA provides the same features as the website. There's no separate app in the App Store or Google Play — the PWA is the official mobile app experience for JustCollabs.
