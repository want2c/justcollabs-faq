# How do I manage my notification settings?

Go to **Settings > Notifications** to control which notifications you receive and how you receive them.

## Email Notifications

### Chat Messages

Choose whether to receive email notifications when you have unread messages:

- **Yes** — Get emailed when you have unread messages
- **No** — No email notifications for messages

### DM Requests

Control email notifications for new DM requests with three options:

- **All** — Get notified for all new DM requests
- **Only Verified** — Only receive notifications from verified creators
- **None** — No email notifications for DM requests

## Push Notifications

Push notifications are delivered directly to your device for real-time alerts.

### Messages

- **Yes** — Get push notifications for new messages
- **No** — No push notifications for messages

### DM Requests

- **All** — Get push notifications for all new DM requests
- **Only Verified** — Only from verified creators
- **None** — No push notifications for DM requests

### Connection Requests

- **Yes** — Get push notifications for connection requests
- **No** — No push notifications for connections

## Enabling Push Notifications

To receive push notifications, you need to enable them in your notification settings. Tap **Enable** in the Push Notifications section. Your browser will ask for permission to send notifications — tap **Allow** to proceed.

You can also tap **Send Test Notification** to verify everything is working correctly.

To stop receiving push notifications, tap **Disable** in the same section.

## Browser Permission

If you previously blocked notification permissions in your browser, you'll need to update your browser settings to allow notifications from JustCollabs before you can enable push notifications.
