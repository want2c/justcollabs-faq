# Can I access JustCollabs on mobile?

Yes! JustCollabs is fully optimized for mobile and works great on your phone or tablet.

## Mobile Web
Our platform is designed as a mobile-first experience with a bottom navigation bar for easy access to all key features: **Performers**, **Roles**, **Messages**, **Requests**, and **Settings**.

## Install as an App (PWA)
For the best experience, you can **install JustCollabs as an app** on your phone. This gives you:
- Full-screen experience without browser bars
- Home screen icon for quick access
- Faster loading times
- Push notifications for new messages and requests

See our [full installation guide](/technical-support/install-as-app) for step-by-step instructions for iPhone, Android, and desktop.

## No App Store Needed
JustCollabs is a Progressive Web App (PWA), so there's no need to download anything from the App Store or Google Play. Simply install it from your browser for a native app-like experience.
