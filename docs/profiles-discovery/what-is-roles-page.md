# What is the Roles page?

The **Roles** page is a dedicated discovery section for finding **industry professionals** who work in the adult content space but aren't necessarily performers. This includes photographers, videographers, directors, editors, social media managers, stylists, and other behind-the-scenes professionals.

## How is Roles different from Performers?

JustCollabs has two main discovery pages, accessible from the **bottom navigation bar**:

| | Performers | Roles |
|---|---|---|
| **Who appears** | Content creators and performers | Industry professionals (photographers, editors, etc.) |
| **Purpose** | Find performers to collaborate with | Find professional services and crew |
| **Access** | Verified users | Verified users only |
| **Filters** | Gender, age, height, weight, body type, position, ethnicity, face, experience | Role type, location |

## How to access the Roles page

1. Tap **Roles** in the bottom navigation bar
2. Browse professionals by location and role type
3. Tap on a profile to learn more
4. Send a message or DM request to connect

## Who appears on the Roles page?

Users who selected non-performer roles during onboarding or in their profile settings will appear here. This includes:

- Producers / Directors
- Camera Operators / Photographers
- Editors
- Social Media Managers
- Accountants / Finance professionals
- Legal Advisors
- Stylists, makeup artists, hairstylists
- Set designers

## Verification requirement

You must be **verified** to access the Roles page. This ensures that all users browsing for professional services are legitimate members of the community.
